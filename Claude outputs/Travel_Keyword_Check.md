### Features the kept tools must include

- **Distance, travel time, halfway point, radius and multi-stop route:** real road distance needs a routing service (for example Google, Mapbox or OSRM). Without one, the tools can only estimate (straight-line distance × a road factor). Decide this before building, because the merged keywords ("google maps", "mapquest", "uk postcodes", "coordinates") expect real routing.
- **Japan Taxi Fare:** one tool covers GO, DiDi, Uber, Lyft, Grab, Bolt and Ola, because they all charge the regulated meter fare. Add a city option (Tokyo, Kyoto, Osaka).
- **Taxi Fare (generic):** needs country/city presets (UK, Canada and others) and an airport flat-fare option. NYC Taxi covers the JFK flat fare and the LaGuardia and Newark surcharges.
- **Avios:** needs an airline option for BA, Iberia and Aer Lingus, with each one's reward chart. Qatar Avios is a separate tool.
- **Qatar Airways Avios:** Qatar now uses Avios, so "qmiles" and "qatar miles" are merged into it.
- **Delta MQD:** MQMs were retired, so "mqm" keywords are answered with MQD figures and a note.
- **Toll Cost (existing):** add vehicle class/axles for "truck" and "semi truck" tolls.
- **Road Trip Budget (existing):** check that it has a tolls field, because the "gas and toll" keywords are merged into it.
- **Miles to Dollars:** needs a programme list (AA, Delta, United, Avios, Aeroplan, Qantas and others) with a default cents-per-point value for each. Hotel programmes go in Hotel Points Value.
- **Fare, toll, baggage and points rules change every year:** each tool should show the date its rates were last checked.
